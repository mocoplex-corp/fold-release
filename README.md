# FoldDisplay releases

Official Windows installers for FoldDisplay by Mocoplex, Inc.

- Choose `x64` for standard Intel or AMD Windows PCs.
- Choose `arm64` for Windows on ARM devices.
- Install the optional virtual-display driver only from a release that explicitly identifies it as Microsoft signed.
